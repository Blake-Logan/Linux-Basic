# Linux Basic

리눅스 기본을 익힐수 있음.

## How to Download

[]초보 전용(복붙하기)
``` bash
	git clone https://github.com/maxlevdev/Linux-Basic.git && \
	cd Linux-Basic && chmod +x setup.sh && \
	./setup.sh && \
```
## 사용법 

`helper`를 입력해 열수 있음.


## 등장하는 명령어

 - pwd
 - ls
 - mkdir
 - rmdir
 - ip
 - 등

## 명령어 정리

| 명령어 | 기능 |
|:---:|:---:|
| ls | 현재 디렉토리 기준 `ls .`과 동일. |
| pwd | 현재 경로 `return` |
| mkdir | 폴더 만들기 |
